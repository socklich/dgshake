# 郊狼3颤栗调教和噤声惩罚

感谢 DG 开源了协议，让我很多想法能做实现。

调教的时候，大家应该都遇到过小 m 乱躲乱叫吧？也都说过"不许躲""不许出声"这种话吧？我突然想到，为什么不用手机自带的传感器做一个触发装置呢？挨打的时候不乖乖趴好、敢乱动，就要做好被严厉电击的准备；敢出声，也会被自动惩罚。一边吃痛、一边又不敢叫出声的样子，一定很有趣。

思路很简单：用手机的陀螺仪和麦克风捕捉动作的变化和声音，换算成波形的频率和强度，再通过 DG 开源的蓝牙协议发给设备。

**颤栗调教**：手机交给对方，或者直接放在身上。对方晃（啪）得越狠，你就被电得越狠。轻晃是挑逗，重晃是惩罚，还会随时冒出一下意外，节奏完全由对方掌控。一个人散步的时候用用，也许也挺放松。

**噤声惩罚**：规则只有一条，不许出声。一出声就被电，可越被电越忍不住……由于是单次惩罚用的, 可以设置的比平时舒适的挡位高15-20档, 比较有惩罚力度. 还加入了一个连击模式, 嘿嘿, 比如一旦忍不住在5秒内连续触发了3次以上, 那么接下来的触发每次都会把波形调的更尖锐(更刺痛)力度更大直到憋住了声音为止才会恢复原本的力度. 参数都可以调.

**音乐模式**：跟着节拍输出，一个人的时候可以用身体去感受音乐。官方APP的这个功能我就没成功开启过不知道为啥. 所以干脆手搓了一个. 这是我最喜欢的功能.

**使用方法**：手机自带的浏览器没有蓝牙权限，需要换一个浏览器：iOS 用 Bluefy，安卓用 Chrome 或 Edge。打开郊狼 3.0，按网页提示开启动作传感器和麦克风权限，就能开始了。 左上角有详细的说明开关, 用过官方程序的应该上手都没难度. 设置在右上角, 如果连不上的话可能是安卓端没有识别出来郊狼主机的名字, 手动从列表里尝试连接信号最强的几个未知设备应该能试出来的.

**网址**：https://highspire.github.io/DG/
