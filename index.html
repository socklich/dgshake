音乐节奏＝放首歌，跟着拍子一下一下来 · 别出声＝不许出声，一出声就挨电
音乐节奏会听几秒算出 BPM，然后预判下一拍、提前出手，准准地踩在拍子上，偶尔漏听也不会断。别出声会先安静地听一会儿记住环境噪音，之后谁发出比这明显大的声音（说话、喘息、叫出声），就电一下；一直出声就隔一会儿再电一下，直到安静下来。

🔥 越挨越重连着来，一下比一下狠
一下接一下不停时，力度逐级往上加；停下来喘口气，就一级一级退回去。
加码规则 起手 / 几下到满 / 喘息

🌡️ 越激动越重动静大了就加码关

一直盯着最近的动静（晃得多猛 / 声音多大）：最近一段比之前明显更激动，力度就随机加一级并保持住；平静回刚才的水平就撤回；之后又更激动，再加一级。三种玩法都生效。
只加在力度不为 0 的那一路，不会超过封顶。刚开始要先观察「最近＋之前」那么长时间才会判断。
调节参数 加多少 / 多敏感 / 怎么比

🎲 随机惊喜冷不丁加重电一下关

打开后，每隔一段猜不到的时间自动来一次“惊喜”：冷不丁加重力度电一下，这段时间里原本的每一下也跟着变重，结束后恢复。只在小狼在线、通道打开时才会来；力度为 0 的那一路不会被偷袭，也不会超过封顶。
三组都是「最少～最多」之间每次随机取：等多久、加多少力（直接加在力度数值上）、持续多久。

📖 玩法 & 日志

1. 右上角「召唤小狼」连上设备。
2. 底部选玩法：「摇一摇」晃手机电；「听声音」跟着音乐电，或者玩「别出声」——一出声就挨电。
3. 先把 A/B 力度调到低档，再打开开关——开关一开就开始；全关＝立刻停。
4. 想加点料：打开「越挨越重」「随机惊喜」，在「手感」里换口味。
5. 切出页面会自动暂停，回来接着玩；没反应就点右上角 🩺。
⚠️ 安全第一：从低档慢慢往上加；电极别跨过心脏（不要一片在胸前一片在背后）；有心脏病、起搏器、癫痫或怀孕请勿使用。玩之前约好安全词，对方一说停，马上关掉通道。
